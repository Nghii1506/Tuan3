Bài 1: Thiết kế Web đáp ứng (Responsive Web Design)

  • Cấu hình thẻ <meta name="viewport" content="width=device-width, initial-scale=1.0"> để tương thích kích thước màn hình thiết bị.
  • Chia bố cục 2 cột .left (70%) và .right (30%) bằng thuộc tính float.
  • Dùng @media (Media Queries) xử lý giao diện: màn hình dưới 768px (xếp dọc 100%), từ 321px - 479px (ẩn cột phải), và chế độ in print (ẩn cột trái).
  • Sử dụng thẻ <picture> và <source> để tự động thay đổi hình ảnh theo độ rộng màn hình (800px, 600px).

Bài 2: Thực hành Chrome DevTools & JavaScript Console (Hack Game Dino)

  • Kỹ thuật Debug & Breakpoint: Đặt điểm dừng trong tab Sources, chuyển khung thực thi sang Runner.update trong Call Stack để trích xuất đối tượng Runner ra biến toàn cục (window.runner = this;).
  • Các câu lệnh điều khiển trên Console:
runner.gameOver = () => {};       // Vô hiệu hóa Game Over (bất tử)
runner.setSpeed(10000);           // Tăng tốc độ chạy của trò chơi
runner.tRex.setJumpVelocity(15);  // Chỉnh độ cao cú nhảy của khủng long
