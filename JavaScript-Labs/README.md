## Danh sách các bài thực hành
- **Lab 08 – JavaScript 1: Language Foundations:** Thực hành nhúng JS nội tuyến/ngoại tuyến, thẻ `<noscript>`, Browser Console, các đối tượng dựng sẵn (`String`, `Date`, `Math`), mảng (`Array`), hàm (`Function`) và đối tượng (`Object`).
- **Lab 09 – JavaScript 2: DOM and Events:** Thực hành truy xuất và thao tác cây DOM, duyệt quan hệ node, xử lý sự kiện (`click`, `mouseover`, `mouseout`, `load`, `focus`, `blur`), gỡ lỗi bằng Breakpoint và kiểm tra dữ liệu biểu mẫu (`Form Validation`).
- **Lab 10 – JavaScript 3: jQuery:** Thực hành tích hợp thư viện jQuery, bộ chọn cơ bản & nâng cao, xâu chuỗi sự kiện (`.on()`, `.off()`), chèn phần tử DOM, hiệu ứng chuyển động (`fadeIn`, `fadeOut`, `slideToggle`, `animate`) và xử lý yêu cầu bất đồng bộ qua `$.get()` / `jqXHR`.
